# 00. 프로젝트 브리프

## 한 줄 목표

공개 산업 표면 결함 이미지 데이터로 재현 가능한 PyTorch 분류 실험을 수행하고, 증강·성능·추론 시간 비교와 이미지 업로드 데모를 포트폴리오로 공개한다.

## 지원 직무 연결

LG이노텍 AI/SW 공고의 컴퓨터비전·영상처리, AI 모델 개발, 데이터 분석, SW 구현 역량을 **공개 데이터 기반 실험 범위에서** 보여준다. AI ISP, GPU/NPU 최적화, 임베디드 장비 연동은 이 프로젝트의 증명 범위가 아니다.

## 사용자 흐름(MVP)

1. 사용자가 이미지 파일을 업로드한다.
2. 앱이 지원 파일인지 검사하고 전처리한다.
3. 학습이 완료된 모델이 예측 클래스와 신뢰도를 표시한다.
4. 신뢰도가 기준값보다 낮으면 `판단 보조 결과 — 재검토 필요`를 표시한다.

## 범위

- PyTorch와 torchvision 기반 이미지 분류
- 고정된 train/validation/test 분할과 seed 기록
- 기준 모델과 증강 모델의 공정한 비교
- Accuracy, macro F1, 클래스별 Precision/Recall/F1, confusion matrix
- 동일 환경의 단일 이미지 추론 시간 측정
- Streamlit 업로드 데모와 최소 테스트

## 명시적 제외 범위

- YOLO 객체 탐지·세그멘테이션·바운딩 박스 라벨링
- 실제 반도체 장비·PLC·카메라 연동
- 실제 현장 불량률·생산성 개선 주장
- ONNX, TensorRT, GPU/NPU 최적화 주장
- 로그인, 데이터베이스, 클라우드/MLOps, 자동 재학습

## 사용자 확인이 필요한 결정

| 항목 | 권장안 | 확정 조건 |
| --- | --- | --- |
| 데이터 | NEU-CLS 공개 강재 표면 결함 분류 데이터 | 라이선스·다운로드 방법·클래스 수를 실제 확인 |
| 프로젝트 제목 | `산업 표면 결함 이미지 분류` | 실제 데이터가 반도체인지 아닌지 확인 후 확정 |
| 모델 | ResNet18 전이학습 | CPU/GPU 환경과 실행 가능 여부 확인 |
| 증강 비교 | 없음 vs 기본 증강 | 같은 분할·seed·학습 조건으로 실행 |
| 신뢰도 임계값 | 초기값 0.60 | validation 결과를 보고 결정, 임의 성능 근거 금지 |
